# デザインリファレンス

## Primary mobile flow

![Re:Me モバイル画面遷移](re-me-mobile-flow.jpg)

この画像は Re:Me の MVP 実装における主要なデザインリファレンスである。

特に以下を実装判断の基準にする。

- モバイルファーストの縦長画面
- 静かな青〜白を基調としたトーン
- 手紙を書く → 未来へ送る → 旅する → 届く → 開封する → 返信する、という一連の遷移
- 通知や受信箱で本文を不用意に露出しないこと
- 「封をする」場合の開封前の特別な体験
- 返信を再び未来へ送ることで、時間をまたいだ会話になること
- UI を分類・管理ツールに寄せすぎず、余白と感情的な体験を重視すること
