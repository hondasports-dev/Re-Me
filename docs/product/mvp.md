# MVP スコープ

## Goal

「未来への予約メッセージ」が面白いかではなく、**時間をまたいで自分と会話する体験が継続利用したくなるか**を検証する。

## MUST

- Social Login
- 手紙本文の作成
- 下書き自動保存
- 写真添付
- 位置情報添付
- ざっくりした届ける時期
- 「未来に任せる」
- 封をする / しない
- 送信前確認
- 送信後編集不可
- 送信済み / 未来を旅する手紙
- サーバー側の到着処理
- 到着通知
- 届いた手紙一覧
- 未開封 / 開封済み
- 開封
- 返信
- 返信を未来へ送る
- 自分の手紙の削除
- RLS 等によるユーザー境界

## SHOULD

- PWA
- Web Push
- 写真 EXIF の除去
- 下書きのローカル保存 / 通信復帰後同期
- 送信直後の短時間 Undo
- 最低限のアカウント復旧導線

## NOT MVP

AI / タグ / カテゴリ / 感情分析 / 統計ダッシュボード / SNS / 公開 / フォロー / いいね / 音声 / 動画 / 複数人送信 / 高度な検索 / 複雑な分岐スレッド / ネイティブアプリ専用機能

## Validation

単純な DAU より以下を重視する。

- 初回作成 → 送信完了率
- 到着した手紙の開封率
- 開封後の返信率
- 返信を再び未来へ送る率
- 2 回目以降の新規手紙送信率
- 数週間 / 数か月後の自然復帰率
- 削除率・通知解除率

Re:Me は「毎日開かせる」ことを成功指標にしない。
