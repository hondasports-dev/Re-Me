# プロダクトビジョン

## ブランド

**Re:Me**

**未来のあなたへ**

追加の説明コピーをブランド直下に置くことは前提としない。プロダクトの意味は体験を通じて理解できるようにする。

## ビジョン

今この瞬間の自分を残し、未来の自分がそれを受け取り、返事をする。

Re:Me は「未来にメッセージを予約送信するサービス」ではなく、**時間そのものを会話の一部にする、自分との往復書簡**を目指す。

## 解決したいこと

人は過去の判断・感情・迷いを、結果を知った後の記憶で上書きしやすい。

Re:Me では、当時の自分を編集できない手紙として固定し、未来に届ける。その結果、以下が自然に生まれる。

- 当時の気持ちとの再会
- 過去の判断との答え合わせ
- 欲しかった物・迷っていたことの変化
- 未来の自分への問い
- 数年にわたる自分との会話

## やらないこと

少なくとも MVP では以下を目的にしない。

- SNS / 公開投稿
- フォロー / いいね
- 日記のカテゴリ管理
- タグ管理
- ToDo / タスク管理
- AI による感情分析・診断
- 行動スコアリング
- 音声 / 動画メッセージ
- 高度な統計・ダッシュボード

## プロダクト原則

### 1. 書く前に分類させない
ユーザーが残したいものは、気持ち・判断・欲しい物・悩み・質問など混在する。最初から型を押し付けず、空白の手紙から始める。

### 2. 「送信」を保存より重くする
送信後は編集できない。「その時の自分」を未来に固定する行為として扱う。

### 3. 待つことを失敗と扱わない
DAU を最大化する体験ではなく、忘れた頃に戻ってくることそのものを価値にする。

### 4. 通知は静かにする
通知で内容を消費させない。「手紙が届いた」という事実だけを伝える。

### 5. 返信も未来へ送る
受け取った時点で会話を閉じず、次の未来へ返信することでスレッドが時間軸に沿って育つ。
